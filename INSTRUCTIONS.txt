Gregnautics — автор сборки Atl4s_n3m0.
Репозиторий обновлений: https://github.com/Atl4s/Gregnautics-MPUC
Ветка: main. Структура файлов:
  meta.json
  versions/0.5.9/changelog.txt

Modpack Update Checker использует RAW-адрес папки с завершающим /.
В config/modpack-update-checker/config.json настроено:
  updateCheckerId = https://raw.githubusercontent.com/Atl4s/Gregnautics-MPUC/main/
  advanced.updateCheckerType = 2
  modpackAuthor = Atl4s_n3m0

Текущая версия сборки: 0.5.9.
Для будущего релиза:
1. Допишите объект с его id в конец массива versions в meta.json.
2. Измените latestVersion на этот id.
3. Добавьте versions/<id>/changelog.txt с описанием изменений.
4. В распространяемой новой сборке измените currentVersion на этот же id.
Старым установленным сборкам currentVersion менять не нужно: по нему определяется обновление.
Не удаляйте предыдущие записи из versions.

Ссылка на загрузку в объекте версии:
  "promotions": { "downloads": { "CurseForge": "https://www.curseforge.com/minecraft/modpacks/gregnautics" } }

Уведомление в главном меню: текст без фона, слева внизу, выше строк версии игры.
Показывается только при доступном обновлении; по нажатию открывает штатный экран MPUC.
При отключённой проверке, сетевой ошибке или актуальной версии уведомление скрыто.
Внешний вид обеспечивает клиентская интеграция Gregnautics Core 0.1.21.
После изменения конфига/ядра полностью перезапустите игру.
